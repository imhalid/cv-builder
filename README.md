## Installation

```bash
yarn install
```

Node 24 is expected (see `.nvmrc`).

## Usage

```bash

yarn run dev
```

## Tests

```bash
yarn test
```

## Analytics

Google Analytics is only loaded when `NEXT_PUBLIC_GA_MEASUREMENT_ID` is set.
